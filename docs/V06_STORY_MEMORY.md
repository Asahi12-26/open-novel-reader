# V0.6 剧情理解与系列记忆

## 整理系列与确认人物

1. 在书架打开「书籍系列」，输入名称并创建。选择已有藏书并点击「加入系列」，用上下箭头调整顺序。移出书籍或移除系列后，小说、书签和阅读记录仍保留。
2. 展开系列人物区域，分别选择两本书和两个人物。核对身份后勾选「确认这是同一个人物」，再提交关联或合并。两个书内人物继续使用原 ID，重名也各自保留。
3. 可以另外勾选共享本机头像。角色自己的头像优先显示，共享头像受两本书的已读边界限制。解除某个角色的关联可将该角色与系列身份分开，也可撤销上次修改并查看历史。原头像和对白记录保留。

系列排序只影响书架整理，适用于前传、外传和非线性故事。每本书的已读位置仍分别计算。

## 先理解剧情，再识别对白

阅读页打开「人物识别」→「整书分析」。先选择「阅读进度模式」或「整本书深度模式」，再核对模型、预计请求次数、费用范围和固定总预算。每本可选系列书显示各自的已读边界。需要复用哪本书的记忆，就在当前任务中勾选相应来源。逐书云同步使用书籍详情中的独立授权。

V0.6 整书任务按小段保存带原文依据的剧情和章节简介，再利用剧情证据、人物历史与明确选中的系列记忆推断对白归属。系统保留未知及可供人工确认的候选。人物说法、AI 推断、原文陈述及人工确认分别记录。剧情冲突保留证据和修订历史，人工确认优先。原有逐章分析和旧整书任务继续使用原协议。

剧情分析可以标记当前片段与已检索的同书事件之间的冲突。悬而未决的 AI 说法暂停复用。跨卷身份仍需要人工核实；跨卷剧情的语义冲突尚待评估。

「返回阅读并继续任务」可在本次已授权会话中收起面板。阅读进度模式跟进已读位置，整本书深度模式按已授权的全书范围运行。暂停、取消或失败后保留已保存分片和预算预留。恢复任务时核对原文、授权范围和固定预算，按提示重新载入会话密钥并授权。到达预算上限时停止，失败请求不会自动重试。估算用于本机预检，实际费用以服务商账单为准。 [任务与预算](BOOK_ANALYSIS.md)

## 查看和修订章节简介

读到章节末尾，展开「本章剧情简介」。需要时点「标记本章读完」保存章节终点。也可从目录打开已生成且已读可见的简介。

可以查看事件原文依据、打开相关人物卡片、修订简介或标记错误。简介修订可从历史恢复，手工剧情确认也会保留先前版本。选择「重新生成简介…」将打开单章授权窗口，使用独立任务和预算，仅处理已读完的这一章。打开章节和查看已保存的简介可离线进行。

整书任务提前分析的简介、身份及事件按阅读位置投影。系列记忆同样受各来源的已读位置和任务勾选范围限制。人物管理保留「显示全书人物信息（可能剧透）」的显式开关。

## 升级、备份与同步

IndexedDB 从 V0.5 的版本 2 增量升级至版本 3，新增系列、人物关联历史、剧情事件、章节简介和对白纠错历史。现有书籍和人物 ID、头像、阅读进度、书签、任务检查点与旧备份格式均保留。V0.6 导出的备份包含当前书库和可见的系列、剧情及修订，任务授权和密钥始终留在会话范围，费用账本留在原设备。

允许云同步的书通过现有私有书籍包同步自己的新数据。系列书籍按各自授权逐本同步，其他卷的成员记录、头像和原文证据随各自书籍包处理。单独在本机创建的空系列通过备份保存。公用设备不同账号分别使用各自的系列范围。

迁移 `20261117084208_preserve_story_records.sql` 保护旧客户端更新书籍时遗漏的剧情扩展，并沿用书籍所有权 RLS。V0.6 通过带登录校验的代理运行这两种分析协议。V0.6.1 使用用户自己的 Key 直连，操作入口见新版指南。 [V0.6.1 指南](V061_LOCAL_FIRST.md)
