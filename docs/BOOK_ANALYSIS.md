# 整本书人物分析

在阅读页点击「章节人物识别」，选择「整书分析」。也可继续使用逐章功能。在设置的 AI 模型页载入自己的会话密钥即可。预处理、估算和查看结果均在本机完成。

V0.6 新整书任务先保存结构化剧情和章节简介，再使用证据识别对白及复核人物。可在预算授权窗口逐本选择系列记忆，来源受各书的已读位置限制。旧任务沿用创建时的分析协议和检查点。 [系列记忆与章节简介](V06_STORY_MEMORY.md)

选择模式、模型与固定总预算，核对请求量和费用估算后勾选授权并开始。整书任务按章节及小分片推进，再对需要确认的内容执行有界复核。V0.6.1 将当前请求需要的对白、邻近正文和人物证据直接发送给 DeepSeek。

- **阅读进度模式**：只发送已读位置之前的完整对白，精确到段落和字符；尚未读完的对白暂不发送。点击「返回阅读并继续任务」可收起面板，在本次已授权会话和同一预算内随阅读推进。追上位置后显示等待状态，不会提前发送未来正文。
- **整本书深度模式**：用户明确选择后分析全书。阅读页默认只展示当前位置可知的人物信息，隐藏未来名称、别名与身份揭示。人物管理中的「显示全书人物信息（可能剧透）」是显式查看选项。

V0.6 增量升级本机数据库，保存任务进度、分析结果和新的剧情数据，保留既有书库和人物 ID。整书任务的授权与预算账本属于当前设备。已选择云同步的小说沿用现有同步流程，保存自己的剧情、简介、人物、对白及纠错结果。密钥只留在会话内存。

暂停在安全检查点生效。取消或关闭任务会停止当前会话并保留已完成结果；收起并继续阅读则保持本次授权。关闭应用、刷新、书库范围或密钥变化后需重新载入密钥并授权继续。已完成的片段保留，失败请求的预留额度继续计入预算。

模型、模式及累计预算在任务创建后固定。单任务预算最高 US$10；失败、取消和超时也可能计费，手动重试仍计入同一累计额度。达到预算、密钥失效、模型不可用或请求异常时停止并保存检查点。费用范围按公开峰价和输出上限估算，实际费用由服务商计算。更换预算或模型须明确新建任务。

跨章人物使用稳定 ID 和带原文位置的证据事件。名称相同不代表同一个人；明确的别名或身份关系也必须能在实际发送的原文上下文中核对。证据不足、代称歧义和低置信度保留未知。人工改名、别名变更与合并留下历史记录，合并保留原人物 ID 的关联，不删除历史对白。人工纠正优先，自动复核不能覆盖。

当前 Beta 的任务层可为其他模型、配音及关系图提供稳定人物 ID、对白位置和可追踪事件；这些扩展本轮不启用。质量样本、独立指标及剩余边界见 [AI_QUALITY.md](AI_QUALITY.md)。V0.4 的新付费真实模型质量评估须另行授权。
