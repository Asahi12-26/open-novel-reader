# 安装与使用

## 选择平台

- **Web / PWA：** 打开 [公开阅读器](https://asahi12-26.github.io/open-novel-reader/)，无需注册即可导入小说。首次联网打开并完成应用缓存后可离线再开；浏览器支持时可用菜单中的安装应用功能。
- **Windows x64** 下载并运行安装向导。安装包未配置发布者签名。 [下载 V0.6.1 Beta 2 EXE](https://github.com/Asahi12-26/open-novel-reader/releases/download/v0.6.1-beta.2/Open-Novel-Reader_0.6.1-beta.2_windows-x64-setup.exe)
- **Android ARM64** 最低 Android 8，V0.6.1 Beta 2 的 versionCode 为 6012。0.2 起的正式签名版可覆盖升级。仍在使用 0.1 开发签名版时，先导出并保留书库备份，再卸载、安装新版并恢复。 [下载 V0.6.1 Beta 2 APK](https://github.com/Asahi12-26/open-novel-reader/releases/download/v0.6.1-beta.2/Open-Novel-Reader_0.6.1-beta.2_android-arm64.apk)

Web、Windows 与 Android 各自保存本机书库。可用 ZIP 在设备间迁移。 [V0.6.1 Beta 2 发布页](https://github.com/Asahi12-26/open-novel-reader/releases/tag/v0.6.1-beta.2) · [下载校验值](https://github.com/Asahi12-26/open-novel-reader/releases/download/v0.6.1-beta.2/SHA256SUMS.txt) · [历史升级验证](../PROJECT_STATUS.md)

## 导入与阅读

1. 点击「导入书籍」，选择自己的 `.txt` 或无 DRM 的 `.epub`。桌面浏览器也可以拖入文件；单个原文件上限为 80 MB。同一个原文件重复导入会去重。
2. 点击封面进入阅读器。使用目录或「上一章 / 下一章」切换章节；阅读位置自动保存，再次打开从保存位置继续。
3. 在「阅读排版设置」中调整字体、字号、行距、页宽与纸白 / 暖笺 / 夜读主题。位置使用段落及字符锚点，调整排版后可继续阅读。
4. 点击「添加当前段落书签」收藏当前位置，通过「查看全部书签」跳转或移除书签。
5. 点击已识别对白的头像查看人物卡片，点击人物标签更正归属。头像可在「阅读排版设置」关闭。 [头像与人物管理](CHARACTER_AVATARS.md)

TXT 支持 UTF-8、GB18030 和带 BOM 的 UTF-16。EPUB 目前按文字阅读，支持目录、段落与封面；暂不呈现内嵌插图、强调 / 链接样式和出版商 CSS，不支持 DRM、漫画及固定版式 EPUB。

## 管理书架与备份

封面旁的「…」打开书籍详情，可修改书名、作者、封面、分类或删除书籍。分类可以在侧栏添加，也可通过「设置」管理。书架提供搜索、排序与最近阅读。

打开「设置 → 数据备份与恢复」，保存完整 ZIP。可以合并 ZIP 或旧 JSON，也可先保存安全备份后明确替换当前本地书库。ZIP 包含书籍、人物、头像、系列、剧情及阅读设置。 [备份和恢复步骤](V061_LOCAL_FIRST.md#完整备份与恢复)

清除网站数据、清除应用数据或卸载可能移除本机书库。更新、换设备或更换 Android 签名包前先导出备份，保留原安装环境直至确认恢复成功。当前恢复文件上限为 256 MiB，尚无大书库分卷导出，请同时保留小说原文件。当前没有二进制自动更新器。

## 配置 AI 和私人云

本地阅读和 AI 无需阅见账号。在「AI 模型」载入自己的 DeepSeek API Key，按需测试连接。测试只查询模型。Key 保存在当前会话内存，刷新或关闭后需重新输入。 [AI 配置步骤](V061_LOCAL_FIRST.md#配置自己的-deepseek-api-key)

已有授权的开发者可通过「私人云同步」登录。同步书籍前，在该书的详情里允许上传。其他读者可使用 ZIP 在设备间迁移。 [私人云说明](CLOUD_SETUP.md)

阅读时打开「章节人物识别」。可选择逐章分析，也可打开「整书分析」，选择阅读进度模式或整本书深度模式。核对请求量、费用估算和固定总预算后勾选授权，任务便会逐段识别对白、保存结果。阅读进度模式仅处理已读内容，收起面板后可随阅读继续。全书结果在阅读页默认按当前阅读位置隐藏剧透。人物管理支持新建、改名与合并，人工纠正优先。

暂停在当前分片后生效，关闭面板会结束当前会话。失败或重启后，已完成分片保留。重启后先载入会话密钥，再重新授权继续原任务。失败和取消的请求仍可能计费，已预留额度计入累计预算。整书任务和预算记录保存在本机，换设备可同步已授权书籍的人物结果。 [整书分析指南](BOOK_ANALYSIS.md)

V0.4 的整书流程使用离线模拟验证，真实整书归属质量待单独授权评估。先前的 V0.3 真机升级、云同步和原创短章真实推理记录保留在项目状态中。 [项目状态](../PROJECT_STATUS.md) · [质量验证](AI_QUALITY.md)
