# 安装与使用

## 选择平台

- **Web / PWA：** 打开 [公开阅读器](https://asahi12-26.github.io/open-novel-reader/)，无需注册即可导入小说。首次联网打开并完成应用缓存后可离线再开；浏览器支持时可用菜单中的安装应用功能。
- **Windows x64：** 从 [成功的原生构建](https://github.com/Asahi12-26/open-novel-reader/actions/runs/41422399968)下载 `windows-x64-installer` 并解压，运行其中的 `.exe`，按向导安装。当前安装程序未做发布者签名；安装、导入、重启续读及本轮覆盖安装保留书籍、章节位置和书签均已验证。
- **Android ARM64：** 在同一构建页下载 `android-arm64-debug-apk` 并解压，将 `.apk` 传到 ARM64 手机后用系统文件管理器安装。本版最低 Android 8，是开发签名包；尚未完成真机安装验证。

GitHub Actions 下载产物可能需要登录 GitHub。[Releases](https://github.com/Asahi12-26/open-novel-reader/releases) 是版本发布和更新入口。Web、Windows 和 Android 的本机书库分别保存，不会自动共享。

## 导入与阅读

1. 点击「导入书籍」，选择自己的 `.txt` 或无 DRM 的 `.epub`。桌面浏览器也可以拖入文件；单个原文件上限为 80 MB。同一个原文件重复导入会去重。
2. 点击封面进入阅读器。使用目录或「上一章 / 下一章」切换章节；阅读位置自动保存，再次打开从保存位置继续。
3. 在「阅读排版设置」中调整字体、字号、行距、页宽与纸白 / 暖笺 / 夜读主题。位置使用段落及字符锚点，调整排版后可继续阅读。
4. 点击「添加当前段落书签」收藏当前位置，通过「查看全部书签」跳转或移除书签。

TXT 支持 UTF-8、GB18030 和带 BOM 的 UTF-16。EPUB 目前按文字阅读，支持目录、段落与封面；暂不呈现内嵌插图、强调 / 链接样式和出版商 CSS，不支持 DRM、漫画及固定版式 EPUB。

## 管理书架与备份

封面旁的「…」打开书籍详情，可修改书名、作者、封面、分类或删除书籍。分类可以在侧栏添加，也可通过「设置与云同步 → 通用与备份」管理。书架提供搜索、排序与最近阅读。

点击书架底部的「导出备份」，或进入「通用与备份 → 导出完整备份」，保存 `.json` 文件。备份包含小说原文、进度、书签及人物数据；不包含 API Key 和账号会话。「恢复备份」先校验数据，再合并到现有书库，保留无关书籍；恢复的书不会因此自动获准上传云端。

清除网站数据、清除应用数据或卸载可能移除本机书库。更新、换设备或更换 Android 签名包前先导出备份，保留原安装环境直至确认恢复成功。当前没有二进制自动更新器。

## 可选的账号、同步与 AI

本地阅读无需账号。要跨设备同步，请先按 [同步与 AI 部署](SYNC_AI.md)配置自己的 Supabase，在「账号与云同步」填写项目 URL 和 publishable / anon 公钥并登录。只有在每本书的详情中明确选择云同步后，才会上传其原文和文件。退出账号不会删除本机书库；共用设备请使用独立浏览器配置或系统账号。

AI 同样需要自己的 Supabase 代理、已登录账号和 DeepSeek API Key。在「AI 模型」中载入密钥，可选择「测试连接（仅查询模型）」。密钥只放本次会话内存，关闭或刷新后需重新输入，不会写入备份或同步记录。

阅读时打开「人物识别」，选择当前章节的模型、查看费用估计并设置预算，勾选本次付费授权后才能启动。默认不分析、不自动重试收费请求；已发送的请求在失败或取消后仍可能被供应商计费。人物标签可点击纠正，人物管理支持新建、改名与合并，人工纠正优先保留。

真实 Supabase 双账号 / 多设备联调与 DeepSeek 收费分析尚未完成；当前没有为用户预置云项目或模型密钥。最新验证范围见 [项目状态](../PROJECT_STATUS.md)。
