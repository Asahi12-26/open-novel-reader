# 整本书人物分析

在阅读页点击「章节人物识别」，选择「整书分析」。原来的逐章功能继续保留。登录后，在设置的 AI 模型页载入自己的会话密钥；预处理、估算、查看结果均不会启动模型请求。

选择模式、模型与固定总预算，核对请求量和费用估算后勾选授权并开始。整书任务自动按章节及小分片处理，再对需要确认的内容执行有界复核，不会把整本小说一次发送。每次请求的对白、必要邻近正文及人物证据经当前 Supabase 代理发送至 DeepSeek。

- **阅读进度模式**：只发送已读位置之前的完整对白，精确到段落和字符；尚未读完的对白暂不发送。点击「返回阅读并继续任务」可收起面板，在本次已授权会话和同一预算内随阅读推进。追上位置后显示等待状态，不会提前发送未来正文。
- **整本书深度模式**：用户明确选择后分析全书。阅读页默认只展示当前位置可知的人物信息，隐藏未来名称、别名与身份揭示。人物管理中的「显示全书人物信息（可能剧透）」是显式查看选项。

任务进度和分析结果保存在本机数据库；没有更换数据库版本或清空旧书库。整书任务的授权与预算账本属于当前设备，不跨设备自动续跑；已选择云同步的小说会沿用现有同步流程保存人物、对白及纠错结果。密钥不写入任务、数据库、备份或云端。

暂停在安全检查点生效。取消或关闭任务会停止当前会话并保留已完成结果；收起并继续阅读则保持本次授权。关闭应用、刷新、账号/代理/密钥变化后不会自动恢复收费请求。重新打开任务时先载入密钥，再明确授权继续；已经完成的片段不会重复发送，失败请求的预留额度不会自动退回。

模型、模式及累计预算在任务创建后固定。单任务预算最高 US$10；失败、取消和超时也可能计费，手动重试仍计入同一累计额度。达到预算、登录失效、模型不可用或请求异常时安全停止。费用范围使用公开峰价和输出上限作保守预检，下界可以为零；它既不是费用承诺，也不是供应商账单硬上限。更换预算或模型须明确新建任务。

跨章人物使用稳定 ID 和带原文位置的证据事件。名称相同不代表同一个人；明确的别名或身份关系也必须能在实际发送的原文上下文中核对。证据不足、代称歧义和低置信度保留未知。人工改名、别名变更与合并留下历史记录，合并保留原人物 ID 的关联，不删除历史对白。人工纠正优先，自动复核不能覆盖。

当前 Beta 的任务层可为其他模型、配音及关系图提供稳定人物 ID、对白位置和可追踪事件；这些扩展本轮不启用。质量样本、独立指标及剩余边界见 [AI_QUALITY.md](AI_QUALITY.md)。V0.4 的新付费真实模型质量评估须另行授权。
