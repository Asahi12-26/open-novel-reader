# 安装与使用

## 选择平台

- **Web / PWA：** 打开 [公开阅读器](https://asahi12-26.github.io/open-novel-reader/)，无需注册即可导入小说。首次联网打开并完成应用缓存后可离线再开；浏览器支持时可用菜单中的安装应用功能。
- **Windows x64：** 本轮目标为 [V0.3 Beta 发布页](https://github.com/Asahi12-26/open-novel-reader/releases/tag/v0.3.0-beta.1)，待实际 EXE 附件生成后运行并按向导安装。0.1 → 0.2 已实测覆盖升级保留测试书、第三章位置、书签和主题；0.3 最终包须另行检查。安装程序未做发布者签名。
- **Android ARM64：** 本轮目标为同一 [V0.3 Beta 发布页](https://github.com/Asahi12-26/open-novel-reader/releases/tag/v0.3.0-beta.1)，待实际 APK 附件生成后传到手机安装。最低 Android 8，固定发布签名，versionCode 3001；0.2 → 0.3 覆盖升级仍待最终包验证。**旧 0.1 开发签名不能直接覆盖安装到 0.2 / 0.3，先在旧版导出书库并保留备份，再卸载迁移，勿直接卸载。** 0.2 起后续版本复用同一签名并递增版本号。

请以发布页实际附件及 `SHA256SUMS.txt` 为准，目标链接不表示本轮包已可下载；[已发布 V0.2](https://github.com/Asahi12-26/open-novel-reader/releases/tag/v0.2.0-beta.1)保留为历史版本。Web、Windows、Android 的本机书库分别保存，登录同一账号并明确允许上传后才会通过云端同步。

## 导入与阅读

1. 点击「导入书籍」，选择自己的 `.txt` 或无 DRM 的 `.epub`。桌面浏览器也可以拖入文件；单个原文件上限为 80 MB。同一个原文件重复导入会去重。
2. 点击封面进入阅读器。使用目录或「上一章 / 下一章」切换章节；阅读位置自动保存，再次打开从保存位置继续。
3. 在「阅读排版设置」中调整字体、字号、行距、页宽与纸白 / 暖笺 / 夜读主题。位置使用段落及字符锚点，调整排版后可继续阅读。
4. 点击「添加当前段落书签」收藏当前位置，通过「查看全部书签」跳转或移除书签。

TXT 支持 UTF-8、GB18030 和带 BOM 的 UTF-16。EPUB 目前按文字阅读，支持目录、段落与封面；暂不呈现内嵌插图、强调 / 链接样式和出版商 CSS，不支持 DRM、漫画及固定版式 EPUB。

## 管理书架与备份

封面旁的「…」打开书籍详情，可修改书名、作者、封面、分类或删除书籍。分类可以在侧栏添加，也可通过「设置与云同步 → 通用与备份」管理。书架提供搜索、排序与最近阅读。

点击书架底部的「导出备份」，或进入「通用与备份 → 导出完整备份」，保存 `.json` 文件。备份包含小说原文、进度、书签及人物数据；不包含 API Key 和账号会话。「恢复备份」先校验数据，再合并到现有书库，保留无关书籍；恢复的书不会因此自动获准上传云端。

清除网站数据、清除应用数据或卸载可能移除本机书库。更新、换设备或更换 Android 签名包前先导出备份，保留原安装环境直至确认恢复成功。当前恢复文件上限为 256 MiB，尚无大书库分卷导出，请同时保留小说原文件。当前没有二进制自动更新器。

## 可选的账号、同步与 AI

本地阅读无需账号。本人测试云项目已内置，使用已确认的测试邮箱在「账号与云同步」登录，三个平台使用同一账号。新注册暂限 Supabase 组织成员邮箱，公开注册与完整密码找回待正式 SMTP 配置后开放。自建用户可在高级选项按 [云服务配置](CLOUD_SETUP.md)填写自己的公开 URL / publishable key。

选择一本小测试书，在详情中允许上传，点击「立即同步」；另一台设备用同一账号登录并同步，检查原文件、章节、书签和阅读设置。断网仍可阅读，恢复连接后继续同步。未选择的本机新书不会自动上传。退出账号不会删除本机书库；共用设备请使用独立浏览器配置或系统账号。

AI 使用已配置的 Supabase 代理、已登录账号和自己的 DeepSeek API Key。本人测试项目的代理已部署。在「AI 模型」先点「检查代理（不调用模型）」即可验证登录和代理，无需密钥、不会访问 DeepSeek。之后自行载入密钥，可选择「测试连接（仅查询模型）」。密钥只放本次会话内存，刷新、退出或切换账号后需重新输入，不会写入备份或同步记录。不要把密钥发到聊天。

阅读时打开「人物识别」，选择要分析的章节和模型、查看费用估计并设置累计预算，勾选本次付费授权后点击开始。任务自动提取对白、判断归属并保存，面板显示分片进度、错误及结果，可进入正文查看与纠正。人物管理支持新建、改名与合并，人工纠正优先保留。

暂停在当前分片后生效，关闭面板会取消在途请求。失败或重启后已完成分片保留，须重新勾选授权再点「从上次进度继续」；不会自动发起收费重试。失败 / 取消的请求仍可能计费，其预留额度不会自动返还。换设备导入的检查点缺少本机预算记录时应新建任务，已有结果仍保留。当前只分析所选章节，不后台分析整本书。

真实 Supabase 双账号隔离、三浏览器同步、断网恢复及本人确认邮件已通过；Android 0.2 本人登录通过，原生同步、重启与离线检查进行中。95 项单元 / 离线测试通过，DeepSeek 收费分析尚未执行、尚未验证，也未预置模型密钥。正式 SMTP 和需 Pro 及以上套餐的泄露密码保护留待公开注册前处理。最新验证范围见 [项目状态](../PROJECT_STATUS.md)。
