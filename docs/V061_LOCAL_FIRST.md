# V0.6.1 本地书库、私人云和独立 AI

## 安装与更新

- Windows x64 运行发布页中的 EXE。安装包内使用 WebView2。Windows 安装包未做 Authenticode 发布者签名。
- Android 使用 ARM64 APK，最低 Android 8。V0.6.1 Beta 1 的应用 ID 仍为 `io.github.opennovelreader.app`，版本号 6011。0.2 及以后使用同一发布证书的版本可覆盖安装。0.1 开发签名不同，从该版本换装前先导出并核对书库备份。
- Web / PWA 首次联网打开，应用缓存完成后可断网重开。浏览器菜单提供安装入口。各平台各自保存本地书库。 [在线版](https://asahi12-26.github.io/open-novel-reader/) · [候选版本发布页](https://github.com/Asahi12-26/open-novel-reader/releases/tag/v0.6.1-beta.1)

从 V0.6 升级沿用原 IndexedDB 名称、Dexie 版本 3、书籍和人物 ID。保留正在使用的浏览器资料、应用数据和 Android 安装，升级后的正文、头像、人物、系列、剧情和旧任务可继续读取。

## 从书架开始

直接导入中文或英文 TXT、无 DRM 的兼容 EPUB，或打开原创试读。书签、精确阅读位置、人物头像、别名、系列关联、剧情、人工纠错和章节简介都保存在设备上。本地设置和已有结果可离线查看或编辑。

清除网站或应用数据、卸载和设备损坏都可能移除本地书库。支持的浏览器可为网站授予持久存储，但用户主动清除仍会移除数据。请定期导出并保留独立副本。 [浏览器存储额度与回收](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)

## 配置自己的 DeepSeek API Key

1. 在「设置 → AI 模型」中打开 DeepSeek 开放平台，用自己的账号创建 Key。
2. 把 Key 贴入阅读器的「配置自己的 API Key」。Key 在当前会话内存中，刷新、关闭或清除后需重新载入。
3. 可选「测试连接」只查询 `GET /models`，用于核对可用型号。阅读时打开「人物识别」选择单章或整书，查看会发送的范围、分片和费用估算，确认预算后启动。

Windows 与 Android 通过系统 WebView，PWA 通过浏览器，直接向 `https://api.deepseek.com` 发 HTTPS 请求。对线上 Web 和原生 WebView 来源分别核对了官方接口的跨域预检与只读鉴权响应。客户端在明确授权后只发必要片段；会话密钥随请求的 Authorization 发送给 DeepSeek。调用由持有该 Key 的账号承担费用。网站或系统 WebView 的网络和跨域行为若变化，请以设置页连接状态为准。 [DeepSeek 官方接口](https://api-docs.deepseek.com/api/list-models)

保留逐章、整书、已读范围和明确选中的系列记忆。待分析正文仅在用户授权请求时外发。每次输出上限 4096 tokens，每请求应用内估算上限 US$0.10，整书累计预算上限 US$10。估算参考峰时缓存未命中报价，Flash 每百万输入及输出 tokens 分别为 US$0.30、1.20，Pro 为 US$1.32、3.96。实际账单由服务商计算，发出后取消或超时仍可能计费。 [官方价格](https://api-docs.deepseek.com/quick_start/pricing/) · [任务与防剧透](BOOK_ANALYSIS.md)

## 完整备份与恢复

在「设置 → 数据备份与恢复」导出 ZIP。ZIP 中的版本清单描述原文、章节、封面、阅读数据、分类、人物、头像、对白、纠错、系列、剧情和简介。原文件与头像作为独立二进制条目保存。设备间传输前，请把文件存到受信任的位置。

- **合并**适合新设备或希望保留现有书籍的情况。支持本版 ZIP 和旧版 JSON。旧版 JSON 只用于合并。
- **替换**针对本机未绑定云账号的书库。先另存当前安全备份，再明确确认替换。云绑定记录和其他账号资料保持原样。恢复操作先验证备份和原文件，再提交一个本地事务。

备份文件上限 256 MiB。应用凭证、会话、DeepSeek Key 和整书收费授权账本不随包传输。旧版原设备升级保留整书检查点；跨设备恢复可查看已保存结果，并按需要启动新任务。云同步仍要逐书许可，恢复本身不会启用上传。

## 开发者的私人云

「设置 → 私人云同步」使用已有开发者账号登录。托管项目关闭新用户注册和匿名登录，保留原邮箱登录与邮箱确认。服务端按可信 Auth UID 白名单判断访问资格，随后继续检查记录和 Storage 路径所有权。退出保留当前设备下载的书和阅读记录；不同使用者共用设备时应使用独立系统或浏览器资料。

大型小说先本机导入可继续阅读。私人云原文件上限 50 MiB，含章节和元数据的包上限 30 MiB。失败时界面显示具体书籍与原因，联网后可重试。普通轮询先读版本，再读取变动数据；双端编辑同一字段产生冲突时保留各自的值，按提示处理。 [配置与验证说明](CLOUD_SETUP.md) · [同步机制](SYNC_AI.md)

私人云仍占用 Supabase 的数据库、存储和流量。Free 套餐提供每项目 500 MB 数据库、1 GB 文件存储以及 5 GB 非缓存和 5 GB 缓存流量。比如保存 20 本各 8 MiB 的小说约占 160 MiB 文件空间，还需另计章节数据包和头像。五台设备各下载一次原文约消耗 800 MiB 下载流量。直连推理不占用本项目代理额度。免费额度与计费规则以服务商的当前价格页为准。 [Supabase 套餐](https://supabase.com/pricing)
