# 人物头像与卡片

阅读页顶部的「人物管理」打开人物网格。可按首次出现位置排序，按名称或别名搜索，也可以手动添加人物。点击人物卡片可修改名称、别名和头像，查看身份变更记录，或跳转到已定位的对白。

正文中，头像紧跟对应对白。点击头像查看资料，点击人物标签更正说话人。未知人物用灰色占位头像，点击可打开纠错。头像和人物标签可以在「阅读排版设置」中独立关闭。

## 头像编辑与合并

选择本机 PNG、JPEG 或静态 WebP。可拖动裁剪区，也可用滑块调整位置和缩放。应用检查图片格式、大小与像素尺寸，保存去除元数据的 256 × 256 PNG，单张最多 300 KiB。上传页显示原图大小限制。

默认配色由稳定人物 ID 决定。改名保留头像。合并保留来源人物的原始对白 ID、身份历史和图片。合并后的卡片优先显示目标头像。目标从未设置过头像时可显示来源头像，仍可在「身份变更记录」查看保留的合并来源头像。「恢复默认头像」会保存该人物的恢复记录。

## 已读范围

人物卡片、出场位置、别名、身份事件和对白列表沿用 V0.4 的按位置投影。未来人物保持隐藏，除非在人物管理中主动开启「显示全书人物信息（可能剧透）」。首次出现位置来自识别记录或用户建立人物时的位置。可在卡片中回看已定位的对白。

## 本机与云端

IndexedDB 版本 2 增加了头像表，图片以 Blob 保存。原有书籍、进度和分析数据沿用已有表。当前可见书库的完整备份含头像，早期备份可继续导入。恢复时为缺少头像记录的人物补齐图片，保留本机已有头像和恢复默认记录。

只有允许云同步的书籍才参与头像同步。同步时，书籍记录保存头像修订与校验值，图片存放在账号私有 Storage 中。不同账户的书籍视图沿用本地隔离方案。自建项目须应用新建的头像存储迁移。 [云同步部署](SYNC_AI.md)

更换头像或恢复默认后，旧云端图片仍保存在私有桶中。当前版本保留这些对象，以免另一台设备正在同步的版本失去图片。

头像功能使用本地图片和内置图标。AI 归属准确率、同名人物和复杂代称的识别质量已登记为下一阶段待办。
